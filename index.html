SIR (Special Intensive Revision - 2002)

Check your name in the old Electoral Roll (SIR 2002) and verify your voter details.

⚠️ ATTENTION: SIR (Special Intensive Revision - 2002) data is based on old voter records. Please enter details exactly as per 2002 records.

📌 Important Guidelines

  • Use correct spelling as per 2002 voter list.
  • Try different name variations if not found.
  • Enter details like Name, Relative Name, Age carefully.
  • Old EPIC / Voter ID number can help for direct search.
  • Data is based on old electoral rolls and may differ from current records.
  • Search is available in local language also (Kannada / Telugu / Hindi).
  • If not found, try searching with district, AC and part number.
